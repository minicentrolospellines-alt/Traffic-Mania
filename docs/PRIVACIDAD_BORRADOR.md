Traffic Mania es un juego de estacionamiento. El progreso, los niveles, las estrellas, las monedas, los tiempos y las preferencias se guardan en el dispositivo. El juego no requiere una cuenta, no ofrece chat y no sincroniza el progreso con un servidor propio. Los datos locales se pueden eliminar borrando los datos de la aplicación o desinstalándola.

La aplicación integra Google AdMob para mostrar anuncios y Google User Messaging Platform para gestionar opciones de consentimiento cuando corresponde. Estos servicios pueden tratar información del dispositivo, identificadores y datos relacionados con los anuncios. Consulta los detalles de Google en https://policies.google.com/privacy y revisa los tratamientos de las versiones del SDK y de la configuración efectiva de esta aplicación antes de publicar esta política.

Desde Ajustes → Privacidad y anuncios puedes consultar las opciones de consentimiento cuando estén disponibles. El juego sigue funcionando sin Internet; la publicidad y sus recompensas requieren conexión y disponibilidad.

La aplicación no solicita ubicación precisa, contactos, cámara o micrófono. No incluye un sistema de cuentas ni compras integradas en esta versión.
